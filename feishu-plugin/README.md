# Chaldeas 图床 - 飞书多维表格插件

在飞书多维表格中上传图片，自动获取图床短链接并填入单元格。

## 功能

- 上传本地图片 → 自动上传到图床 → 填入当前单元格
- 传入图片 URL → 自动下载到图床 → 填入当前单元格
- 拖拽支持、预览、进度条

## 部署

插件文件托管在图床服务器上（与你已有的图床共用同一域名）：

```bash
# 将 feishu-plugin 目录复制到图床的 public 目录
cp -r feishu-plugin /home/ImageBed/public/
pm2 restart chaldeas
```

验证是否可访问：`https://your-domain.com/feishu-plugin/index.html`

## 安装到飞书

### 1. 创建飞书应用

1. 打开 [飞书开放平台](https://open.feishu.cn)
2. 点击「创建应用」→「企业自建应用」
3. 填写应用名称（如 "Chaldeas 图床"）

### 2. 开启多维表格插件

1. 进入应用 →「能力配置」→ 搜索「多维表格」
2. 开启「网页应用」插件能力
3. 配置插件入口地址：`https://your-domain.com/feishu-plugin/index.html`
4. 设置图标、应用描述

### 3. 配置权限

在「权限管理」中添加：

- `bitable:app` — 多维表格读写权限
- 如果使用 URL 上传（跨域拉取图片），添加 `https://*` 网络权限

### 4. 发布应用

1. 进入「版本管理与发布」
2. 创建版本，填写版本号 `1.0.0`
3. 提交发布审核（企业自建应用通常秒过）

### 5. 在多维表格中使用

1. 打开飞书多维表格
2. 点击右上角「插件」→「获取插件」
3. 找到「Chaldeas 图床」并添加
4. 在表格中选中要填入 URL 的单元格
5. 打开侧边栏插件 → 上传图片 → 点击「填入当前单元格」

## 使用流程

```
[图片列]               [URL 列（空）]
  🖼️ 照片.jpg   →      Chaldeas 插件 → 上传 → 自动填入
                       → https://your-domain.com/i/aB3xK.jpg
```

你可以设置图片列和 URL 列，每次在图片列插入图片后，选中 URL 列的对应单元格，打开插件上传即可。
